# 地图浏览交互验收

## 自动检查

`npm test`：两档边界、方向吸附、连续往返、显隐缓冲、拖动取消、窗口变化、安全区、键盘开关、实体键盘零高度事件、筛选与滚动回顶、统一内容卡、一步返回、长内容、返回和拖动不缩放地图、隐藏点事件过滤及卸载清理。

`npm run check`：源文件语法、页面引用、TDesign 本地构建文件。

## 微信开发者工具

1. 首次进入：真实内容标记位于可见地图区域，顶部胶囊、定位按钮和底栏正常；仅显式 demoMode=true 时显示六个示例。未配置云环境须显示配置状态。
2. 拖动：仅有收起和展开两档。慢拖、快甩、反向拖动和拖到一半取消；上拉过程中列表可见，临界位置轻微抖动不反复切换标题。“列表／收起”按钮可直接切换。
3. 搜索：点击输入不拖动面板；关键词与分类共同筛选，清空只清关键词，标记和列表一致。示例模式可输入“公园”验证两条；真实数据按已发布内容验证。
4. 滚动：先滚动列表再筛选，多次重复均能回顶；拖动面板不会带动列表滚动。
5. 列表选点：点条目一次即打开完整内容卡，包含标题、地点、全文；长内容内部滚动，详情没有拖动把手。点“返回浏览”一次回到刚看的条目，保留搜索、分类和高亮。
6. 地图选点：点地图标记或气泡，打开与列表相同的内容卡；返回保持刚才的地图视野，拖动列表面板也不缩放地图。
7. 底栏：五项入口进入真实业务页，中间“＋”突出；返回首页保留地图和筛选。完整业务路径见 [验收表](acceptance.md)。

## 真机补充

- iOS 有手势条、Android 无底部安全区各验证一次。
- 键盘弹出：搜索框与结果在键盘上方，底栏暂隐；键盘关闭后保持结果展开，不需要再上拉。“收起”按钮在输入中也只需点一次。
- 开始输入后直接返回、切后台、重新打开，不能留下键盘高度或拖动状态。
- 允许和拒绝定位、定位失败重试；地图原生层的标记点击和取景需确认。
- 搜索长文本、选择最后一条、快速切换分类后点地图，确认无错误选点或遮挡。

自动测试模拟小程序页面状态与 API，不替代真机键盘、原生地图叠层与实际触摸体验的验证。
