
启动开发者工具本地自动化接口，以下路径按本机安装调整：


## 两个用户 A、B 联调

用不同微信账号和测试数据，勿以开发者工具重复窗口假装不同身份。

1. A 首次打开可先浏览；发布时才设置昵称，不要求手机号。A 发布文字和公开地点；文字审核通过后 B 在相同地图区域可见。
2. A 发布九张图片，观察压缩、逐张上传进度及待审核状态。B 在审核完成前不可见内容和图片；通过后点列表或标记一次打开完整卡片、预览图片。
3. B 搜索、切分类，地图标记与列表一致。返回保留关键词、分类、选中条目及视野；分页不重复标记和条目。
4. B 点赞、取消、再点赞；收藏、取消；评论。A 收到对应通知，重复相同请求不重复计数／通知；B 的个人收藏正确。
5. A 发布未来活动，上限 1。B 报名，双方记录和通知对应；再次报名不重复计数。B 取消释放名额，A 收到撤销通知。
6. 若可使用第三测试账号，与 B 同时抢最后一个名额，只有一人成功。也可在隔离测试环境用相同业务接口并发执行；不能用客户端伪造 OPENID。
7. A 取消已报名活动，B 收取消通知且不能再次报名。已经开始、结束、满员或取消均不能新报名。
8. A 删除动态；B 的旧收藏、消息来源和分享链接均不可再次读取正文，能明确返回，消息仍可标已读。
9. B 举报 A 内容；管理员查看全文和图片，下架或结案；产生 audit，普通账号不能进入管理接口。
10. 从微信分享打开指定内容，仍使用统一卡片，来源不存在有明确错误。
11. A 选择内置 Cos 形象与角色标签，在“我的”主动开启地图出现；B 在相同区域看到头像标记、地点和喊话，点标记或名单一次打开人物卡。
12. A 上传自定义 Cos 照片，审核通过前 B 只看到已审核的旧头像／内置形象；审核通过后显示新照片，拒绝或超时可恢复使用内置形象。
13. A 选择公开地点后出现在地图；切换到当前位置需再次主动取定位。两种状态均两小时后不再出现在他人地图，A 可手动停止；切后台、重启后确认没有持续位置更新。
14. A 发起好友申请，B 在消息页同意或忽略；重试不重复通知，双方好友列表一致，好友状态回到地图后及时更新。
15. A 使用快捷喊话模板或自定义短文字，B 可见新喊话；不合规文本不会公开，未开启地图出现时引导先选择地点或当前位置。

## 权限与失败验收

- [ ] B 用 A 的内容 ID 删除、取消，被拒绝；传 ownerId/isAdmin/status/counter 不能冒用或改值。
- [ ] B 无法读写 A 的通知或个人资料；无法客户端直接修改任何业务集合。
- [ ] 客户端调用回调／清理被规则或上下文检查拒绝，伪造 pass 不能公开内容。
- [ ] 发布／评论请求重试返回原结果，不多一条；点赞、收藏与报名使用相同 active 重试不重复。
- [ ] 平台 risky、服务异常、图片未返回、全部图片未通过时不公开；管理员也不能越过平台拒绝。
- [ ] 审核中删帖后晚到回调不恢复内容；旧回调不覆盖新审核。
- [ ] 上传时断网，留在发布页重试；已成功图片复用。退出后文字草稿恢复，需重新选图。
- [ ] 关闭网络加载首页出现错误和重试，不展示本地示例；恢复网络后可真正重新加载。
- [ ] 在独立测试环境检查过期废弃／删除图片清理，当前公开引用图片保留；清理与发布并发不产生坏引用。
