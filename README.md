# 地图与滑动区域 · 微信小程序

参考 `D:\prj\map_qh_xy\map_q` 的 `MapBackground.vue`、`ContentArea.vue`、`DragSearchBar.vue`、`useLayout.js` 和 `layoutConfig.js`，将核心交互整理为独立的微信原生小程序。参考项目保持不变。

## 打开

1. 微信开发者工具 → 导入项目 → 选择 `D:\prj\map`。
2. 确认 `project.config.json` 中的 AppID 是你有权限的小程序。定位等能力请使用真实 AppID 验证。
3. 本项目已安装并构建 TDesign 组件，可直接编译。全新下载时先运行 `npm ci --ignore-scripts`，再在微信开发者工具中选择“工具 → 构建 npm”。基础库请选择当前稳定版本。
4. 真机定位前，在小程序后台补充用户隐私保护指引中的位置信息用途，并配置位置接口所需的权限。项目仅在点击定位按钮时请求位置。

## 保留的内容

- 微信原生地图，初始视野为成都，支持缩放和拖动；采用自定义导航模式，地图延伸至顶部，保留系统状态信息和微信胶囊。
- 五项底栏：首页、服务、＋发布、消息、我的。使用 TDesign TabBar、TabBarItem 和 Icon 组件；中央保留 48px 黑色发布按钮，不使用多页面 tabBar。首页为当前页面，其余入口提示暂未开放。
- 底栏主体从 58px 收紧到 48px，普通入口在有手势条的设备上稍向下居中，减少文字下方的视觉留白。安全区由外层统一计算，关闭组件自身的安全区和占位，防止重复增加高度。
- 白色底部面板只有两档：84px 收起档，以及扣除底栏和安全区后可用高度 55% 的展开档。
- 拖动把手或点击“列表／收起”切换档位，内部列表独立滚动；输入框不接收拖动手势。
- 搜索和分类筛选，点击示例条目将地图移到对应坐标。
- 当前位置定位，拒绝权限和地图错误提示，底部安全区适配。
- 地图标记与筛选结果一致：点地图标记或列表条目都直接打开同一张完整内容卡，显示标题、地点和全文。地图自动取景时避开顶部胶囊与底部面板。
- 内容卡固定在展开档，长文内部滚动，不需要拖动。只有一个“返回浏览”入口，返回保留筛选和高亮，并定位到刚查看的条目。
- 搜索只针对本地示例地点与内容，支持清空、结果数量、无结果恢复；切换分类和重复搜索都会回到列表顶部。
- 输入即筛选，软键盘出现后面板位于键盘上方、底栏暂时隐藏；关闭键盘后仍保持结果展开。
- 地图仅在首次加载、查看内容、结束搜索或主动定位时调整；拖动面板和返回浏览不会自动缩放。
- 布局尺寸统一在 `utils/panel.js` 的 `LAYOUT` 中配置；拖动内容显隐使用 16px / 8px 缓冲，避免细小往返造成标题跳动。

面板中六条内容均为本地示例，不是真实动态。当前按“先只保留地图和滑动区域”的要求，未接入账号、发帖、点赞、聊天、商城、订单或后端。

## 验证

运行 `npm test` 检查面板、键盘、地图联动与滚动恢复逻辑，`npm run check` 检查页面引用、组件构建、JSON 和 JavaScript 语法。具体交互验收见 `docs/interaction-checklist.md`。

## UI 组件库

接入 [TDesign 微信小程序组件库](https://github.com/Tencent/tdesign-miniprogram)，固定版本 `1.17.0`（MIT 协议）。仅在页面注册需要的组件，底栏、搜索和返回按钮使用同一套 Icon。以后可以继续按需引入按钮、弹层等组件。

组件 npm 包保存在 `node_modules`，微信可运行构建位于 `miniprogram_npm`。请勿手动修改构建目录，升级依赖后重新执行“构建 npm”。

开发者工具及真机验收：地图铺满背景，底栏与加号正常；两档拖动和独立滚动正常；两种点击入口一次打开内容，一次返回；搜索、清空、分类、定位和安全区正常。特别确认返回和拖动不缩放地图。原生地图与键盘仍需在微信环境验证。
